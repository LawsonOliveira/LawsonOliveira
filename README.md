# 👋 Hi there

I'm Lawson Oliveira Lima, an AI/ML Engineer with a Master's degree from CentraleSupélec (France) and a Bachelor's degree in Electrical Engineering from the Federal University of Ceará (Brazil).

I currently work as an AI Engineer (Backend & Infra) at Casa dos Ventos, a TotalEnergies joint venture, building multi-agent systems, agentic RAG and OCR pipelines in production.

# 🚀 Expertise

- **Agentic AI:** multi-agent orchestration, RAG, MCP, guardrails, LLMOps with Langfuse.
- **Geometric Deep Learning:** GNNs with PyTorch Geometric, distributed training on HPC clusters (Slurm, multi-GPU).
- **Machine Learning:** time series, anomaly detection, audio and image processing.
- **Software & Infra:** backend, DevSecOps, Docker, Terraform, Google Cloud.

# 🧩 Featured projects

- [Kitchen Assistant](https://github.com/LawsonOliveira/kitchen-assistant): multi-agent assistant (Hermes agents over A2A, MCP, guardrails, Langfuse, evals).
- [Emotion Recognition](https://github.com/LawsonOliveira/Emotion_recognition): emotion detection model deployed with a web interface.
- [Anomaly Detection in ECGs](https://github.com/LawsonOliveira/Anomaly_detection): LSTM-VAE for time series anomalies.
- [Version Control System](https://github.com/LawsonOliveira/VCS): a CLI version control system in Rust.
- [PINN](https://github.com/LawsonOliveira/PINN): physics-informed neural networks for fluid dynamics.
